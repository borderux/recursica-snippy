Snippy is now built on version 1.5.0 of the Recursica Mantine adapter, set up the way the adapter's setup guide describes, with Snippy's own Recursica Forge theme export. The panel header now has the design system's Close button, which closes the side panel, and pressing Escape closes the side panel too (except while a dialog is open or a capture is under way, where Escape still only cancels that).
