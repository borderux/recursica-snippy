The panel header now shows a "New Version Available" link next to the version when a newer Snippy has been released on GitHub. Snippy also now has a fixed extension id, so updating by replacing the files in its folder (see the README's "Updating" section) keeps your saved comments. Moving to this version from 0.4.0 or earlier starts with an empty session, so download a report of any review in progress first.
