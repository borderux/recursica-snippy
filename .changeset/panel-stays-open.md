"snippy": minor
---

Snippy now opens in Chrome's side panel. It stays open as you move between pages, sites and tabs in a window, always showing the active tab's comments, and Chrome's own side panel controls resize and close it. Captures work as before, without hiding the panel: drag on the page for a screenshot, or pick an element by mouse or with the arrow keys and Enter, even with focus in the panel. Add annotations opens the screenshot in a new tab beside the page, with the main window's room to draw in; saving or cancelling closes it and returns to the page. On pages Snippy can't reach (browser pages, the Chrome Web Store) the panel says so and Add is turned off. Snippy is now Chrome only; the Firefox version is discontinued. The extension now needs access to all websites and Chrome's side panel permission, which Chrome asks you to approve when it updates. The panel's stored width is no longer used and is removed.
